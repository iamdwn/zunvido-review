Background download demonstration

Google Play foreground service declaration · FOREGROUND_SERVICE_DATA_SYNC

Open video directly · Download video

App: ZunVido 1.1.2 (version code 4), com.tools.zunvido, target API 36.

  1. The user starts a media download in ZunVido.
  2. The download continues after returning to the Android home screen, with an ongoing progress notification.
  3. The completed file is saved on the device and can be opened.
  4. The user can cancel a download. The foreground service stops when no active downloads remain.

Recorded from the native app on an Android 16 (API 36) emulator. The emulator build uses x86_64 native libraries with the same app source as version 1.1.2. The recording is edited into three segments, with idle time removed; app screens and download progress are real.

The demonstration downloads a generated test-pattern video from a local HTTP server limited to approximately 128 KiB/s so progress remains visible. A public copy is available as sample.mp4. The sample contains no personal or third-party media.
