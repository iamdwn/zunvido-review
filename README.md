# ZunVido Google Play review video

[Watch the demonstration](https://iamdwn.github.io/zunvido-review/)

[Direct MP4 video](https://iamdwn.github.io/zunvido-review/foreground-service-demo.mp4)

This video demonstrates user-initiated downloads using the Android `FOREGROUND_SERVICE_DATA_SYNC` permission in ZunVido 1.1.2 (version code 4), package `com.tools.zunvido`, target API 36.

The recording shows a download continuing with a progress notification after leaving the app, opening the completed file, and cancelling a second download. The foreground service stops when no downloads remain active.

Recorded on an Android 16 emulator using x86_64 native libraries and the same app source as version 1.1.2. Three recorded segments are joined with idle time removed. There are no simulated app screens or simulated progress indicators.

A generated test video is served locally at approximately 128 KiB/s for visible download progress. A public copy is included as `sample.mp4` for reproduction. The sample contains no personal or third-party media.

This repository contains review assets only.
